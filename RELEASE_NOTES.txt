AFewBuds Web Cloud Career Transfer 1

- Existing browser careers can be backed up to the signed-in AFewBuds account before launch.
- A Home Screen/PWA install with no local career restores the cloud career before Godot starts.
- If both device and cloud have different saves, the player chooses which one to keep.
- The losing save is never overwritten until the player explicitly chooses.
- Autosync uploads newer local saves approximately every 30 seconds while signed in.
- Guest players continue to use local saves only.
- Game runtime remains AFewBuds 0.7.9-beta.19.
