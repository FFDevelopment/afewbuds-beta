AFewBuds beta.17 GitHub Pages upload

1. Extract this ZIP.
2. Copy ALL contents into the existing local afewbuds-beta repository root.
3. Replace matching old game files when prompted.
4. Keep .git and your repository settings.
5. Commit to main, then Push origin.
6. Wait for GitHub Actions -> Pages build and deployment to turn green.

Important:
- Upload the CONTENTS of this folder, not the ZIP itself.
- index.html, index.pck, index.wasm and afewbuds-update.html stay at repo root.
- admin/ and shared/ stay as folders at repo root.
- SUPABASE_SETUP/ is documentation/schema only; it is harmless on Pages but you may keep it locally instead if preferred.
